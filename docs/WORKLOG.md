## 2026-09-30 — 補模擬老師鐘點費，讓「選老師→財務自動帶入」可實測

**做了什麼**：新增非破壞性腳本 `supabase/set-contact-rates.ts`（`npm run seed:rates`），只對 `default_rate` 尚未設定的老師補模擬收費，依角色關鍵字給金額，四種付款方式各有代表（月結／每次 LINE Pay／預繳累扣／預付一學期）。實跑補了 15 位（含手動建的「小杜」），9 位非收費對象自動略過。

**為什麼**：使用者回報「財務區塊看不出連動或帶出」。根因＝`seed.ts` 建立老師時（L187）只填 name/role/phone，沒填收費欄位，所以 `event-modal.tsx:256` 的自動帶入條件（選到的人物 `default_rate != null`）永遠不成立。功能本身是好的，缺的是資料。

**已知落差**：帳號目前只有 1 個費用類別「數學課」，presets 的家教費/才藝費/健身課對不上，所以「費用類別」不會自動帶（金額、付款方式正常帶）。要讓類別也連動需先在設定建立對應類別，或改 presets 指向現有類別。

**下一步**：使用者實測自動帶入是否顯示灰底提示與正確金額。

## 2026-09-30 — 費用類別自動帶入補齊 + 標籤防呆

**做了什麼**：

2. 標籤防呆：新增 `src/lib/tags.ts` 的 `tagKey()`（NFKC 全半形正規化＋去空白＋小寫）。兩層套用——
   - 伺服器 `resolveTagIds`（events.ts）：改撈全部標籤、以 key 比對，變體（LINE Pay／line pay／ｌｉｎｅpay）自動歸到既有標籤，不再新建分裂列。語音/匯入也都走這條，一併涵蓋。

## 2026-09-30 — 月曆空檔改「聚焦某人」（全景+標名），用真實空檔引擎

**做了什麼**：把「空檔對象」從「篩選（隱藏其他人）」改為「聚焦」語意——
- 月曆（MonthView）：顯示全部行程，非所選對象**淡化**（opacity），空檔改用 `availability.freeOnDay` 依所選對象在工作時段（08–22）計算**真實空檔**並**標上名字**（如「小明 空 3小時」）。格內門檻 1h、當天面板門檻 30 分且可點空檔直接新增。
- 週/日（TimeGridView）：同樣淡化非對象、空檔改算對象並標名。
- calendar-view：改傳全部 events + `gapFilter`，衝突改用全部 events 計算。

**為什麼**：舊版空檔是「相鄰兩筆行程的縫」不分人，會把阿姨/小孩/Peggy 混在一條時間軸；且小孩當天只有 1 筆課時算不出他整段空閒。使用者要在外層月曆看「特定人（尤其小孩）的空檔」以便安排。經確認採「全景+標名」方案（其他行程仍看得到當背景）。

**驗證**：`npm run typecheck` 綠；lint 僅既有檔（reminder-notifier/event-modal）問題，本次三檔零新增。

**下一步**：使用者在部署站實測聚焦切換、淡化與標名空檔；工作時段 08–22 若不符需求可調或做成可選。

**追加**：聚焦對象改為**記住上次選擇**（localStorage `execcal:gapTarget`，仿 digest-view/app-data 慣例以 effect 讀取）。使用者反映「全部行程混合空白無法歸給單一人」，確認後採「預設聚焦對象」方案——設一次，之後進月曆自動套用該對象的空檔，不用每次手動切。清除即回 all。

**追加 2**：新增聚焦選項「**本人（未指定人物）**」（gapTarget=`self`，match＝`contactNames.length===0`）。使用者心智：沒掛人物的行程＝本人（Peggy）的，掛了人物就是那個人的。這讓 Peggy 自己的空檔也能列出（配合記住上次，可設為預設）。

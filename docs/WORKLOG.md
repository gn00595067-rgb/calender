## 2026-09-30 — 補模擬老師鐘點費，讓「選老師→財務自動帶入」可實測

**做了什麼**：新增非破壞性腳本 `supabase/set-contact-rates.ts`（`npm run seed:rates`），只對 `default_rate` 尚未設定的老師補模擬收費，依角色關鍵字給金額，四種付款方式各有代表（月結／每次 LINE Pay／預繳累扣／預付一學期）。實跑補了 15 位（含手動建的「小杜」），9 位非收費對象自動略過。

**為什麼**：使用者回報「財務區塊看不出連動或帶出」。根因＝`seed.ts` 建立老師時（L187）只填 name/role/phone，沒填收費欄位，所以 `event-modal.tsx:256` 的自動帶入條件（選到的人物 `default_rate != null`）永遠不成立。功能本身是好的，缺的是資料。

**已知落差**：帳號目前只有 1 個費用類別「數學課」，presets 的家教費/才藝費/健身課對不上，所以「費用類別」不會自動帶（金額、付款方式正常帶）。要讓類別也連動需先在設定建立對應類別，或改 presets 指向現有類別。

**下一步**：使用者實測自動帶入是否顯示灰底提示與正確金額。

## 2026-09-30 — 費用類別自動帶入補齊 + 標籤防呆

**做了什麼**：
1. 升級 `set-contact-rates.ts`：自動補建缺少的費用類別（家教費／才藝費／健身課，帶正確分群 child/adult），並把 15 位老師的「預設類別」接上。之前帳號只有「數學課」1 個類別，導致類別無法自動帶入。now 選到老師 → 金額＋付款方式＋費用類別全帶入。
2. 標籤防呆：新增 `src/lib/tags.ts` 的 `tagKey()`（NFKC 全半形正規化＋去空白＋小寫）。兩層套用——
   - 伺服器 `resolveTagIds`（events.ts）：改撈全部標籤、以 key 比對，變體（LINE Pay／line pay／ｌｉｎｅpay）自動歸到既有標籤，不再新建分裂列。語音/匯入也都走這條，一併涵蓋。
   - 輸入元件 `tag-input.tsx`：打字時吸附既有標籤的正式寫法、同義不重複加、建議清單依 key 排除已選。

**為什麼**：統計要準，「同一標籤」不能因大小寫/全半形/空白不同被算成多個。刻意不合併「數學 vs 數學課」（語意不同，強合併會錯）。

**驗證**：`npm run typecheck` 綠；掃描現有 21 個標籤無變體重複，舊資料乾淨無需清理。

**下一步**：使用者實測；若日後仍見亂建，再評估升級為「標籤受管清單」（見 DECISIONS）。

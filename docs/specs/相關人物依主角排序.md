# 相關人物選單：依主角排序（不再用整體次數）

狀態：已實作（2026-10-06）
日期：2026-10-06

## 問題
Peggy：相關人物用使用次數排序，老師因每週上課次數一定最多，永遠排最前；Peggy 替自己排行程時要找的客戶／同事反而在後面。

## 設計
- 依「目前選的主角」決定誰排前面：
  - 主角是本人（is_self，或沒選主角）→ 本人行程裡出現過的相關人物。
  - 主角是小孩／豪哥 → 那個人行程裡出現過的人（老師、教練）。
- 排序：出現在幾個**系列**（重複行程整個系列算 1）→ 次數 → 名字。避免每週一堂的老師灌爆次數。
- 選單分兩區：「常和 ○○ 一起」、「其他人物」（依名字）；人物多於 8 位時頂部有搜尋框（名字或稱謂，如「老師」「客戶」）。
- 主角欄維持原本的整體使用次數排序。

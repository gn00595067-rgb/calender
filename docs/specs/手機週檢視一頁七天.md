# 手機週檢視：一頁看完 7 天，而且要比 Google 清楚

狀態：已實作（2026-10-12）
日期：2026-10-12

## 問題
Peggy：手機打開「週」只看得到三天，要左右滑；希望像 Google 日曆一頁看完一週，
**但要比 Google 清楚**——Google 那樣字小、被切成「Ph/oe/nix」、重疊的看不出是什麼行程。
（10/06 為了讓標題看得到，週檢視每天最少 6rem＋左右滑，結果一次只剩 3 天。）

## 設計（只影響手機 < 640px 的週檢視；日檢視、電腦版不變）
- 不左右滑：7 天均分螢幕寬，左側時間欄縮窄（3rem → 2.25rem）。
- 每小時加高（48 → 64px），1 小時的行程也放得下約 3 行字；最短 30px。
- 卡片只放**標題**（11px 粗體），時間看左邊刻度；卡片夠高（≥ 約 80 分鐘）才在底部補開始時間。
- 只在必要時斷字（英文名不會被逐字母切開）。
- 底色加深、不透明（用月曆 chip 的色），一眼分得出分類。
- 重疊行程不左右平分（一張只剩 20px），改**層疊**：後開始的往右縮排疊上去，先開始的標題保留整欄寬。
- 空檔縮成「空 6h」；最後結束線只標時間（不寫「結束」）。
- 點表頭的日期 → 跳到那天的日檢視看完整細節（手機、電腦都適用）。

## 不做（看回饋）
- 週檢視時間軸改滿版高度（目前維持 60vh 內捲動）。
- 衝突在手機週檢視只用紅色左條表示（不加紅框，以免層疊時框線混在一起）。

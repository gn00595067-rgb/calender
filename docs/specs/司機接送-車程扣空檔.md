# 司機接送：車程也算沒空，從空檔扣掉

狀態：已實作（2026-10-06）
日期：2026-10-06

## 問題
Peggy 回饋：14:00 海蒂會議有標司機接送，但月曆上的空檔還是算到 14:00 前，
實際上 13:30 就要上車，回來也要時間——空檔被高估，照著排會撞到。

## 規則
- 單程車程＝原本的「去程提早上車」分鐘數（預設 30；選「不算車程」＝0）。回程假設一樣久。
- 來回：開始前 N 分＋結束後 N 分都算沒空；只有去程：只扣開始前；只有回程：只扣結束後。
- 只影響**空檔／負荷計算**（`busyOnDay`），行程卡片本身的時間與位置不變。
- 誰沒空？跟著行程的主角走（本人的行程扣本人空檔，哥哥的扣哥哥的）。

## 表單
- 欄位改名「單程車程（空檔會扣掉）」，選項「約 N 分鐘」；只有回程時也顯示（之前隱藏）。
- 預覽多一行：「回程 15:00 上車…，約 15:30 到」「含車程 13:30–15:30 都不算空檔」。

## 為什麼不加新欄位
- 去程提早上車本來就等於車程，沿用即可：免 migration、既有標司機的行程立刻生效。
- 去回程車程不同的情況少見，等回饋再拆成兩個欄位。

## 不做（看回饋）
- 依地址自動估車程（Google Maps API，要金鑰與費用）。
- 在週／日檢視把車程畫成淡色區塊。

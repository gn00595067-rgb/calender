# 語音新增：說話的人當主角

## 問題（使用者 11/10 回饋）
豪哥用自己的帳號（hao@execcal.test）語音新增「我明天打球」，主角沒帶豪哥，存下來被當成 Peggy姐（本人）的行程。

## 原因
行程「沒指定主角＝本人」，而本人是 Peggy 人物管理裡勾「本人」的 Peggy姐。豪哥看的是 Peggy 分享的行事曆，語音照舊把「我」留空 → 變成 Peggy 的。

## 規則
- 登入者的顯示名稱＝某位家人的名字或別名，且那位不是「本人」→ 他就是「說話的人」。
- 說話的人存在時：句子裡的「我」、或沒講是誰的行程，主角＝說話的人；「我和哥哥」→ 兩位都是主角；講「Peggy姐的…」照講的帶。
- 模型沒填主角時，程式保底帶說話的人（不靠模型）。
- 標題照既有規則加「-豪哥」。
- Peggy 自己登入：不變（沒主角＝本人）。

## 範圍
只改語音新增。手動「＋新增行程」的主角預設、月曆「本人」空檔不動，等回饋。

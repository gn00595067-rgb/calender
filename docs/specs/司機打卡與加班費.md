## 加班怎麼算
**原則：打卡時間落在固定班表以外的部分＝加班。**
1. 當天實際工作時段＝上班打卡～下班打卡。
2. 加班＝實際時段 − 班表時段（上班前提早、下班後延後都算）。
3. 休息時間被叫出車：該段也算工時（試算表說明）→ 算進當天加班。
4. 當天加班時數**合併**後套級距：

| 日別 | 級距 | 倍率 |
|---|---|---|
| 平日（二～六） | 第 1–2 小時 | 時薪 × 1⅓ |
| | 第 3–4 小時 | 時薪 × 1⅔ |
| 休息日（週一） | 第 1–2 小時 | × 1⅓ |
| | 第 3–8 小時 | × 1⅔ |
| | 第 9–12 小時 | × 2⅔ |
| 例假日（週日） | 原則不得出勤；天災事變等例外：當日工資加倍並補假 | 標記人工處理 |
| 國定假日 | 第 1–8 小時：加發 1 日工資；第 9–10 小時 × 1⅓；第 11–12 小時 × 1⅔ | |

5. 檢核：每日（正常＋加班）不得超過 12 小時；每月加班不得超過 46 小時 → 超過時月報標紅提醒（不擋打卡）。
6. 每小時加班費取到整數元並不低於法定（試算表做法：280、348、556）。

### 例子（週五班表 07:30–20:00）
打卡 07:25～21:40 → 下班後 20:00–21:40 加班 1 小時 40 分（提早 5 分依「計算單位」規則處理）→ 平日第 1–2 小時級距 → 1.67h × 280。

## 畫面
1. **司機手機首頁（司機帳號）**：今天日期、今天班表、大按鈕「上班打卡」／「下班打卡」、今天需要接送的行程（沿用司機行程）。
2. **打卡紀錄（Peggy）**：一個月一張表，每天：上班、下班、正常時數、加班時數、加班費、備註；可補登／修改（留修改紀錄）。
3. **月報**：加班總時數、各級距時數、加班費合計、預估薪資（未扣勞健保）；46／12 小時檢核；可列印／匯出。
4. **設定 → 司機班表與薪資**：月薪、每天班表、國定假日清單。

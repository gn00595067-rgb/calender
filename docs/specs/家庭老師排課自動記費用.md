# 家庭老師排課自動記費用（Elsa 11/17 回饋）

## 為什麼
Elsa 11/17 看了〈家庭老師操作指南〉：
1. 「相關人物」要選，因為關係到是哪位老師上課，也會列在他的費用統計。家庭老師在填小孩行程時，要註明是哪一位老師、一對一或一對二，指南沒寫。
2. 家庭老師看不到費用，所以費用欄位不會出現，沒辦法讓他選一對一或一對二。
3. 角色分清楚：**家庭老師**要管小孩所有課和每一位家教老師；**家教老師**只看得到自己負責的上課時間、科目和回饋。
4. 指南的顏色（藍＝哥哥、粉＝妹妹、綠＝兄妹）是不是只給家庭老師用？Elsa 的主行事曆小孩都是藍色，綠色是外傭。

查到的現況：
- 家庭老師＝行事曆分享身分「老師」（scheduler，0025）；家教老師＝人物管理的「老師帳號」（/teach，0021）。權限本來就符合第 3 點，只是測試帳號和指南把家庭老師叫成「家教老師」。
- 家庭老師存課時**完全不會產生費用**（財務表只給 owner／editor 寫），所以他排的課就算選了老師，也不會進 Peggy 的「依老師」統計和月底結算。
- 家庭老師讀不到 Peggy 的人物表（RLS 只看得到已經掛在行程上的人），排新課時選不到 Peggy 設好收費的老師；用「＋」新增的人掛在家庭老師自己名下，沒有收費方案。
- 收費方案（鐘點費）的讀取規則是「看得到這位老師就看得到方案」，家庭老師可以直接查到鐘點費。
- 顏色是每個行事曆的擁有者設定的，分享出去的人看到一樣的顏色；指南上的顏色只是測試帳號的示範色。

## 做法（使用者選「自動記費用」）
1. **伺服器代記費用**（`src/lib/scheduler-finance.ts`）：家庭老師新增／修改自己排的課後，伺服器用管理金鑰在家長帳下記一筆費用，判斷和家長新增時的預設一致：
   - 收費老師＝相關人物裡第一位有收費方案的人；
   - 上課形式＝`pickPlan`（依「誰的行程」選了幾個小孩：1 位＝1對1、2 位＝1對2；有指定小孩的方案優先）；
   - 金額＝`planAmount`（時薪 × 時數＋加收）；月薪制記 0 元已結清；
   - 類別、方向、付款方式照老師的預設；預繳方式掛這位老師第一個啟用中的帳戶；結清狀態照付款方式預設（月結＝未結清）。
   - 整日、標題像談話開會（`looksNonLesson`）、沒選收費老師 → 不記；原本有記的刪掉。
   - 家長已經付款的（已結清、且付款方式不是一建立就結清的那種）不再自動改、刪。
   - 刪課時一併刪掉未付款的代記費用，不留「無關聯行程」的費用。
2. **表單提示**（只有家庭老師看得到）：相關人物下方
   - 沒選人：黃框「家教課請在這裡選上課的老師，家長那邊才會記到這堂課的費用」；
   - 選了收費老師：藍框「會記成 ○○ 的 1對2 課（依「誰的行程」自動判斷）…你看不到金額」；
   - 選的人沒有收費或不像上課：灰字說明不記費用。
3. **家庭老師的人物選單**：另外跟伺服器拿家長的人物名單，只給家人和老師（有收費方案或設了老師類型），只有名字與稱謂；Peggy 公事的客戶、電話、備註、費率都不給。
4. **0029**：收費方案只給擁有者，以及在擁有者某個行事曆是 owner／editor（看得到金額）的人讀。
5. **指南**改名〈家庭老師操作指南〉，補「選老師、1對1／1對2」步驟與截圖、「家教老師是另一種帳號」說明；顏色改寫成「跟 Peggy 姐的行事曆一樣，看標題後面的名字最準」。
6. 測試沙盒加「數學老師（測試）」：1對1 時薪 1,200、1對2 時薪 1,800、月結；家庭老師顯示名稱改「家庭老師（測試）」。

## 不做（MVP）
- 家庭老師手動切 1對1／1對2（一律依「誰的行程」判斷；要 1對1 就把另一個小孩拿掉）。
- 家庭老師用「＋」新增的人改掛到家長名下（仍掛自己名下、不會記費用；表單會顯示「不會記上課費」）。
- 顏色本身不改：要不要把「哥哥+妹妹」改掉綠色（Elsa：綠色是外傭）由 Peggy／Elsa 決定。
- `contacts.default_rate`（舊單一費率欄位）家庭老師仍讀得到看得見的老師那列；新程式不用它，之後再清。

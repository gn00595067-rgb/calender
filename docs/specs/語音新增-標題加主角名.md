# 語音新增：非本人的行程，標題自動加主角名

狀態：實作中
日期：2026-10-06

## 問題
Peggy 回饋：月曆上「打球」看不出是誰的，要往下看第二行才知道是豪哥。
希望語音新增時，非 Peggy 本人的行程標題直接帶人名：「打球-豪哥」，掃一眼就懂。

## 規則
- 「非本人」＝有指定**主角**（沿用既有語意：沒主角＝本人 Peggy）。
- 標題格式：`<標題>-<主角名>`；多位主角用「、」連接：`鋼琴課-哥哥、妹妹`。
- **只加主角，不加相關人物**（老師、外佣等是「一起做／服務的人」，不是行程主人）。
- 標題裡已出現該主角名就不重複加（避免「打球-豪哥-豪哥」）。
- 由程式決定後綴（不靠模型），結果穩定。

## 範圍（MVP）
- 只改語音新增帶入的標題；手動新增、既有行程不動。
- 帶入後使用者在表單改主角，標題不會跟著改（可自行修改標題）。
- 「過去習慣」依標題分組時，先去掉主角名後綴，讓「打球」與「打球-豪哥」算同一種行程。

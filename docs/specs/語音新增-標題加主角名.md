# 非本人的行程，標題自動加主角名（語音／手動／既有行程）

狀態：已實作（2026-10-06）
日期：2026-10-06

## 問題
Peggy 回饋：月曆上「打球」看不出是誰的，要往下看第二行才知道是豪哥。
希望語音新增時，非 Peggy 本人的行程標題直接帶人名：「打球-豪哥」，掃一眼就懂。

## 規則
- 「非本人」＝有指定**主角**（沿用既有語意：沒主角＝本人 Peggy）。
- 「Peggy姐」本人也可能被設成主角（如美甲、礁溪）→ 她的名字**不加**（名字含 Peggy／本人即視為本人）。
- 標題格式：`<標題>-<主角名>`；多位主角用「、」連接：`鋼琴課-哥哥、妹妹`。
- **只加主角，不加相關人物**（老師、醫師等是「一起做／服務的人」，不是行程主人）。外佣在人物裡是家人、會被設成主角，所以會加（如「做好便當-外佣」）。
- 標題裡已出現該主角名就不重複加（避免「打球-豪哥-豪哥」）。
- 由程式決定後綴（不靠模型），結果穩定。

## 範圍
- 語音新增：解析結果帶入表單時就已加好，使用者可先看到。
- 手動新增／編輯：存檔時由伺服器加（`src/lib/actions/events.ts`）；先去掉舊的家人名後綴再加目前主角，
  所以改主角、拿掉主角，標題會跟著變。共用邏輯在 `src/lib/subject-title.ts`。
- 既有行程：`npm run backfill:titles`（預覽）／`-- --apply`（寫入），可重跑。
- 「過去習慣」依標題分組時，先去掉主角名後綴，讓「打球」與「打球-豪哥」算同一種行程。

### 畫面
1. **行事曆**：只顯示一個區塊「家庭老師到班 17:00–22:00」（就是現有的行程，不新增細項）。
2. **點進區塊**：行程詳情多兩個分頁
   - 「預排課表」：當天週課表裡這段時間的項目（唯讀；去家教填報改）。
   - 「工作報告」：當天的工作紀錄（時間、內容、大項／細項、工時），老師可以直接新增。
3. **老師記工時**（手機）：「＋ 一筆」→ 選大項／細項（常用的放前面）→ 開始、結束（預設接上一筆的結束時間）→ 內容一句 → 存。一天結束可以「複製昨天的格式」。
4. **週報**（老師與 Peggy 都看得到）：選週 → 自動表格（大項小計、細項、工時、佔比）＋ AI 擬的執行概述（老師可改）＋ 老師寫重點檢討 → 送出；Peggy 端在「工作效益」看，並且跟月薪比較（已有）。

## 四、需求 2 的做法（搬移與重複比對）
- 只**複製**測試版行程到 Peggy 帳號，**測試版不刪**。
- 分類對應：測試版「哥哥／妹妹／哥哥+妹妹」→ Peggy 的同名分類；人物依名字對到 Peggy 的人物（數學 Jack → Jack…），對不到的列出來。
- 自動找重複：同一天、同一個小孩、時間重疊（或標題相近）→ 標紅並排「A＝Elsa key 的／B＝老師 key 的」，選「以 A 為主／以 B 為主／都留」。
- **預設以 A 為主**（Elsa 的有司機、計費）；選 A 時把 B 上的**回饋、課程進度搬到 A**，B 不另外建；老師看得到 A（Phoenix 正式帳號是家庭老師身分就看得到）。
- B 才有的行程（Elsa 沒 key 的）直接建在 Peggy 帳號，登錄人是 Phoenix 的正式帳號。

# 語音：一句話多筆行程、用語音回答追問、地點加在標題

狀態：已實作（2026-10-06）
日期：2026-10-06

## 問題（Peggy 回饋）
1. 語音助理會提出問題，卻只能手動改選單回答，不能直接用講的。
2. 一句話講兩件事（「10點開會，下午3點美甲」）只建立第一筆，第二筆要自己重講／手動建。
3. 語音有講地點時，希望標題後面自動用括號加上地點：「與總經理開會(公司)」。

## 設計
### 一句話多筆
- 模型輸出改為 `events: []`（最多 5 筆，依時間排序）；不再問「要不要一起建立」。
- 前端排隊逐筆帶入表單，面板顯示「第 1 / 2 筆（存好後自動帶下一筆）」。
- 存檔成功 → 自動開下一筆；沒存就關掉 → 跳提示「還有 N 筆沒建立」＋「建立下一筆」按鈕（15 秒）。

### 用語音回答追問
- 語音面板底部按鈕：有疑問時「用語音回答上面的問題」，沒有疑問時「用語音補充或修改」。
- 回答＋**表單現值**（使用者可能已手動改）＋先前問題 → API 追問模式 → 只改回答相關欄位、回傳 1 筆 → 表單重新帶入。
- 追問後不再重複「沒指定主角＝本人」的規則提醒（使用者已有機會回答）。

### 地點加在標題
- 有講地點（不是依過去習慣帶入的）→ 標題後加「(地點)」；已含地點字樣不重複加。
- 與主角名後綴併用：「美甲(延吉街)-豪哥」。只套語音新增；手動新增不變。

## 不做（看回饋）
- 手動新增也自動加地點。
- 一次把多筆全部直接存（仍逐筆確認，避免辨識錯誤污染行事曆）。

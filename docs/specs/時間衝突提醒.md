# 時間衝突提醒（儲存前）

## 需求來源
Peggy（2026-09-30）：排行程時若同時段已有其他行程，希望系統提醒；
可選「照原本既定行程」或「放棄舊行程」，避免忘記去取消舊的。

## 行為
- 按「儲存」時，先查同時段（與新行程時間重疊）的既有行程。
  - 範圍：使用者可存取的**所有**分類（不受目前顯示篩選影響）。
  - 排除：自己（編輯時）、整日行程（整日不佔時段）。
  - 新行程本身為整日、或為「新增重複行程」時不檢查（MVP 範圍外）。
- 無衝突 → 直接儲存（行為不變）。
- 有衝突 → 表單換成衝突面板，逐筆列出（日期時間、標題、分類、主角），三個選擇：
  1. **返回修改**：回表單改時間。
  2. **放棄新行程**：關閉視窗，不存。
  3. **儲存**：存新行程；面板中**勾選**的舊行程於儲存成功後刪除（按鈕文字即時顯示「並刪除 N 筆舊行程」）。
     預設不勾（刪除不可復原）；沒有編輯權限的分類不能勾。重複行程只刪該筆。
- 舊行程掛有財務紀錄時，勾選旁提示「財務紀錄會保留」（finance_records.event_id 為 on delete set null）。

## 不做（先觀察）
- 重複行程逐堂比對衝突。
- 「延後／改時間」舊行程（目前只提供刪除）。

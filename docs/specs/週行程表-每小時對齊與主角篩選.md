# 週行程表：每小時對齊＋從今天起多範圍＋主角篩選

狀態：已實作（2026-10-30）

## 問題
Peggy 手做的週表看得懂「上午／下午有事」，但舊版週行程表只把行程丟進「上午／中午／下午／晚上」四格，看不出幾點到幾點被佔；名稱還帶時間、地點、備註，太擠。也只能一次看「週一～週日」一週，且家人的行程全部混在一起。

## 做法
1. **每小時對齊**：縱軸每小時一格（預設 8–21 點，有更早／更晚行程自動撐開，整段期間共用同一範圍，各週上下對齊）；色塊依實際起訖定位、高度＝時長。左邊保留「上午／中午／下午／晚上」時段帶當底色分區。今天有紅色現在時刻線。
2. **名稱極簡**：只放標題、去掉開頭時間（0730小游→小游）；色塊夠高才加一行小字起訖（7:30–9）。地點、備註不放（點開詳情看）。
3. **從今天起**：預設今天起 7 天；快捷「1 週／2 週／1 個月／半年」，每 7 天一段往下排；左右箭頭一次移動一個範圍，「今天」回到今天。網址 `?start=&days=` 仍可用（區間總覽連過來）。
4. **主角多選**：「看誰的」：本人＋每位家人一顆，點了切換顯示／隱藏。行程歸屬＝主角中的家人；沒指定家人主角就算本人。記在瀏覽器（存「隱藏了誰」，之後新增的家人預設會出現）。

## 注意
- 兩個以上主角的行程，只要其中一位有選就會出現。
- 半年＝26 段，列印時每段不拆頁。

# 語音：確認畫面簡化、日期換算、談話不計費（測試回饋 #6、#7）

狀態：已實作（2026-10-13）

## 問題
- #7：語音確認要看的項目太多，簡單行程也要從頭看到尾；說「隔三週」卻變成隔二週；改了日期也沒提醒時間衝突。
- #6：說「跟 Phoenix 談話」被自動帶上 500 元上課費。

## 做法
- **確認畫面**：語音帶入時預設只顯示一句話摘要（時　誰　事（地），隨修改即時更新）＋要司機／費用／重點標籤＋助理的問題；全部欄位收起來，「要改細節？展開全部欄位」才展開。儲存鈕改叫「沒問題，新增」。原句、依過去紀錄帶入、假設只在展開時顯示。有設定本人時不再提醒「沒指定主角＝本人」（摘要已寫出本人名字）。
- **日期換算**：送給 AI 的訊息附 14 週的日期對照表（本週／下週／下下週／N 週後那週，週一到週日），規定相對日期一律查表；「隔 N 週」「N 週後」＝今天＋7×N 天。「每三週」等系統沒有的週期改成指定日期。
- **衝突提醒**：原本新增重複／指定日期的行程時完全跳過衝突檢查；改成逐一比對每個日期的同一時段（重複日期展開邏輯抽到 `src/lib/recurrence.ts`，前後端共用）。
- **談話不計費**：AI 多判斷 `isLesson`（上課才 true）；手動新增時標題含談話、會議、開會、面談、討論、溝通等也算不是上課。不是上課 → 選到有收費方案的老師也不自動打開財務，財務區顯示說明；要記費用（例如算在上班時間的行政工作）手動打開即可，會照方案帶入金額。

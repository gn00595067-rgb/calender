# 家教老師填報（專科老師上課紀錄＋家庭老師每日回報）

狀態：第一、二期已實作（2026-11-02；0023、0024）
來源：《家教老師填報表單 需求說明 草案 v2》（2026/11/02，立齊 Rick＝哥哥、以瑄 Iris＝妹妹）

## 問題
現在數學、國文老師的上課紀錄、家庭老師的每日回饋、週課表散在 LINE 和 Excel 截圖，家長很難：
- 核對每位老師每月時數（鐘點費）；
- 看出各科上到哪個單元、兄妹各科吸收程度有沒有變差；
- 不漏掉「需家長處理」的聯繫、採購報名、專題截止日。

## 地基（沿用 10/29 老師帳號，0021）
- 老師帳號＝人物管理裡一位非家人人物＋`teacher_user_id`；登入一律導到 `/teach`。
- 老師看不到 events／財務表，只透過 security definer 函式拿需要的資料。

## 分期
### 第一期（本次）
1. 人物設定：老師類型（專科／家庭）、可填科目、是否開放給家庭老師看、家庭老師各工作類別時薪（只有家長看得到）；家人可勾「上課學生」（遷移時預設哥哥、妹妹）。
2. 老師端 `/teach`（手機優先）分頁：
   - **填報**：專科老師＝上課紀錄（§二、§三，無照片）；家庭老師＝每日回報（§4-1～4-8，無照片），區塊可展開，沒內容就略過。
   - **我的紀錄**：自己填過的，可修改、刪除；顯示最後修改時間。
   - **時數**：本月／上月自己的時數（家庭老師依工作類別），不顯示金額。
   - **專科紀錄**（只有家庭老師）：家長開放的專科老師紀錄，唯讀。
   - **我的課與回饋**：原有功能保留。
3. 家長端「家教填報」頁 `/tutoring`：
   - **紀錄**：全部紀錄，依老師／科目／學生／月份篩選；點開看詳情、留言（老師端看得到並可回覆）；顯示「最後修改」。
   - **報表**：時數統計（每位老師每月；家庭老師依工作類別，乘上時薪算金額）、各科進度（每科最近單元）、吸收程度趨勢（兄妹各科 0–100% 隨日期）、待辦提醒（需家長處理的聯繫、未完成採購報名、專題截止日）。
4. 和行事曆的連動：專科老師選日期時，若那天行事曆有他的課，一鍵帶入時間並連到那堂課；存檔時自動在那堂課寫一則回饋摘要（作者＝老師），所以「缺回饋不付款」、「學習回饋」頁照常運作。

### 第二期（0024，已實作）
- **照片**（§3-3、§4-8）：私有 bucket `tutor-files`，路徑 `r/<紀錄 id>/…`；看得到那筆紀錄的人才看得到（家庭老師看得到開放的專科紀錄照片）。可拍照或從相簿多選，上傳前縮到長邊 1600px JPEG。存檔順序：先存紀錄（決定 id）→ 上傳 → 失敗的照片從內容拿掉並警告。刪紀錄先刪照片。
- **家庭老師週課表**（§五）：家長與家庭老師可編輯；一天多個時段（項目、負責老師、重點標籤）；勾「考試」整天橘色醒目；請假／停課紅字刪除線；「複製上週」；過渡期上傳課表圖片（`s/<家長 id>/<週一>/…`）。**連動**：家庭老師每日回報可一鍵「從週課表帶入」當天家庭老師負責、沒請假停課的時段。
- **課本單元清單**（§七）：家長在「單元清單」分頁依科目一行一個；老師填單元時出現可點的選項，沒建的科目照樣手打。
- **匯出**：家長端「匯出本月」CSV（Excel 可開；上課紀錄每位學生一列、每日回報一天一列摘要）。
- **待辦已處理**：家長按「已處理」收起，可顯示已處理並取消。
- **專題進度**：階段或 0–100%（擇一或都填）；選「完成」或 100% 就不再列待辦。
- **資料庫強制**：專科老師只能填自己的可填科目；每日回報限家庭老師（`tutor_report_allowed`）。

## 待確認事項的處理（§九-1）
「日期由老師自填，還是家長先排好讓老師選？」→ 兩者都支援：老師自填日期與時間；若那天行事曆已排了他的課，表單上方出現「帶入 10/30 19:00–20:30 數學」一鍵帶入並連結那堂課。不必先決定。

## 資料（migration 0023）
- `contacts`：`tutor_kind`（`specialist`／`home`／null）、`tutor_subjects text[]`、`tutor_shared boolean`（專科老師紀錄開放給家庭老師）、`is_student boolean`。
- `tutor_rate_settings`：家庭老師 {工作類別: 時薪}，只有家長讀寫（不放 contacts：共用行事曆的人讀得到 contacts）。
- `tutor_reports`：一筆＝一次上課紀錄或一天的回報。
  - `owner_id`（家長）、`teacher_contact_id`、`author_id`（老師帳號）、`kind`（`lesson`／`daily`）、`report_date`、`subject`、`start_time`／`end_time`（上課紀錄）、`mode`（1對1／1對2）、`student_ids uuid[]`、`event_id`（連到行事曆那堂課，選填）、`event_note_id`（自動回饋摘要）、`content jsonb`（各區塊）、`minutes`（系統算的時數，報表用）、`created_at`、`updated_at`。
- `tutor_report_comments`：家長留言、老師回覆。
- 權限（RLS）：
  - 家長（owner）：讀、刪全部；不能改老師的內容，只能留言。
  - 老師：新增／修改／刪除自己寫的（`author_id`），只能用自己連結的人物、科目限可填科目（前端限制）。
  - 家庭老師：另外讀得到同一位家長、`tutor_shared` 的專科老師紀錄。
  - 老師權限依「老師人物」判斷（不是登入帳號），換帳號仍看得到、改得到舊紀錄。
  - 連結的行事曆課必須是自己的課、回饋摘要必須是自己寫的（資料庫檢查）。
  - 留言：只有家長與那筆的老師讀寫（家庭老師看得到開放的專科紀錄，但看不到雙方的留言）。
  - 刪紀錄時資料庫一併刪掉那則行事曆回饋摘要。修改時同一堂課原地更新摘要（保留家長端做過的依小孩拆分）。
- 函式 `my_tutor_profile()`：回傳老師自己的人物、類型、可填科目、上課學生名單（不含時薪）。

## 時數
- 上課紀錄：迄－起。
- 每日回報：各工作時段加總，依工作類別分開；金額＝時數×家長設定的時薪（只在家長端計算顯示）。

## UX 注意
- 老師多在下課後用手機填：欄位大、滑桿 0–100% 每 5% 一格、必填欄位標紅、送出前檢查。
- 學生回饋依勾選的學生各一張卡（只勾妹妹就只出現妹妹）。
- 家庭老師每日回報一天只能一筆：同一天再按「填報」會打開當天那筆繼續改。

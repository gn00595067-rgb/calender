# 多週總覽（找空週）＋週行程表（測試回饋 #5）

狀態：已實作（2026-10-13）

## 問題
會議提到：要看本週、下週、未來數月（找適合旅遊的日期、有沒有一整週的空檔）；Peggy 想要像她手做的一週表那樣（行程＋相關備忘）一目了然，Google 週檢視擠在一起不好看。

## 做法
1. 區間總覽多兩個快速鍵：「下週」「未來 3 個月」（從本週一起 13 週）。
2. 區間超過 7 天時顯示「每週忙碌程度」：一列一週、七格，格子數字＝那天 8:00–22:00 被行程佔掉的時數（重疊合併），越深越忙；有整天行程加橘點；4 週以上時標出最空的 3 週。點一列跳到那週明細。可配合「空檔對象」只看自己。
3. 新頁「週行程表」（左側選單；區間總覽右上也有按鈕）：七天 × 整天／上午（11:30 前）／中午（13:30 前）／下午（17:00 前）／晚上，每格「時間＋標題（地點）」、底色依分類、下方灰字是備註；重點行程紅字。標題開頭已自帶時間（如 0730小游）就不重複加時間。「列印／存 PDF」只印表格，A4 橫向。手機上表格本身可左右滑。

## 注意
- 「最空」是依目前行事曆的資料算的：很久以後的週還沒排行程時也會顯示最空，要自己判斷。

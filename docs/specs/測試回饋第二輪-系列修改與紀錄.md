# 測試回饋第二輪（雅雲 10/25）：系列修改、修改紀錄、接送回程、標題主角名

來源：「行事曆 測試回饋」匯出 2026/10/28，編號 5-2、10-2、11～17。

## 需求與做法
| # | 問題 | 做法 |
|---|---|---|
| 5-2 | 區間總覽很多塊只看到時間、看不到內容 | 色塊改成標題在上、可折多行填滿；標題已含時間（0730小游）不再另列時間；夠高才補開始時間；並排窄欄字縮小、不再切成「17-2…」 |
| 10-2 | 要分開看新增紀錄、修改紀錄，可依日期／類別排序 | 新增紀錄頁加「新增紀錄／修改紀錄」切換；排序：輸入（修改）時間、行程日期近→遠、遠→近、依分類。修改紀錄用新欄位 `events.edited_at/edited_by`（0019），只有按「編輯→儲存」才算 |
| 11 | 達達老師 10/11 起改 2 小時、收費不變，不影響 10/10 前 | 財務紀錄本來就是存檔當下的快照，改方案不會動舊紀錄。做法：人物管理把方案改成每堂 1000 → 打開 10/11 那堂 →「此筆與之後全部」改時間與金額（#13 修好後之後每堂一起改） |
| 12 | 本人與豪哥一起上的課，標題只要「時間＋老師」，不要「-豪哥」 | 標題下加「標題後面加上主角名」勾選，取消就不加（並去掉舊後綴），即時顯示存檔後標題。編輯時：有主角但標題沒後綴＝之前拿掉過，預設不勾 |
| 13 | 「此筆與之後全部」改費用／時間，之後各筆的錢沒變、報表也沒變 | 原本人物、標籤、財務只改點開那一筆。改成跟著套用範圍：之後每一筆的主角、相關人物、標籤、費用都一起改；結清狀態：點開那筆照表單，其他保留原本 |
| 14 | 從公司出發「來回」，回程會送回公司而不是家 | 新增「回程送到（空白＝家）」；上車地點只影響去程。只有去程不顯示回程欄、只有回程不顯示上車欄。舊的「只有回程」資料沿用原本存在上車地點的值 |
| 15 | 刪重複行程要預設僅此筆 | 刪除視窗改成兩個選項、預設「僅此筆」，只有一顆紅鈕「刪除這一筆」；選了之後全部按鈕才變「刪除此筆與之後全部」 |
| 16 | 修改行程時重複欄位不見了 | 單筆行程編輯時可設重複（存檔後這筆變系列、多建之後的日期）；重複行程編輯時顯示「每週，到 X/X，共 N 次」，可「延長重複到」 |
| 17 | 改時間後費用要重算的灰字很容易沒看到 | 這次編輯改了時長或上課形式、且金額與方案不符 → 紅框紅字「金額要重算：依方案應為…目前填…」＋「改成 NT$…」鈕。只是打開舊行程（方案後來改過）不變紅 |

## 邊界
- 延長重複只支援有規則的系列（每天／每週／每兩週／每月）；指定日期系列要加日期請另新增。
- 提早結束系列：在要刪的第一筆按刪除 →「此筆與之後全部」。
- 修改紀錄從 0019 套用後才開始記；刪除不列入。
- 已經錯的舊資料（如 10/13 康橋 12,600）要再開一次、選「此筆與之後全部」存檔才會更新。

# 老師登錄小孩行程

## 為什麼（Peggy 11/9 LINE）
> 我需要一版老師可以登錄小孩的行事曆。他也只看得到小孩的行事曆，比如家教課、游泳課、學校要帶什麼東西，他可以登記可以看，然後合併到我跟我先生的行事曆。我也可以登錄小孩的、我幫她安排了哪些活動，這樣我跟我先生可以看到完整的。老師只負責登錄，還有看到小孩的或者是我幫小孩追加的。

## 做法
沿用「設定 → 分享」，新增分享身分 **老師**（`scheduler`）：
- 只看得到被分享的行事曆（小孩的）裡的**全部行程**，包含 Peggy／豪哥加的。
- 可以在這些行事曆**新增**行程。
- 只能**修改／刪除自己登錄的**行程；Peggy 加的只能看。
- **看不到金額**（不能設定費用）。
- 可以寫回饋。
- 老師加的行程本來就在 Peggy 的行事曆裡，所以 Peggy、豪哥（已被分享）自動看得到。

Peggy 自己操作：設定 → 分享 → 選小孩的行事曆 → 輸入老師 Email、身分選「老師」→ 老師用該 Email 註冊即可看到。

## 跟現有「老師帳號」的差別
人物管理裡的「老師帳號」是家教填報用，登入只會看到填報頁。這個是行事曆分享，登入看到的是一般行事曆畫面（只有小孩的）。

## 不做（MVP）
- 老師看不到人物清單、標籤（那是 Peggy 帳號的），新增行程時人物欄是空的。
- 老師註冊後會有自己預設的 4 個空行事曆。

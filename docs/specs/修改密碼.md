# 修改密碼

## 為什麼
登入後沒有任何地方能改自己的密碼；測試帳號（boss／tutor）仍是 test1234，老師帳號只能由家長「重設密碼」。

## 範圍（MVP）
- 主畫面右上角使用者選單、老師頁（/teach）頂端，都有「修改密碼」。
- 對話框：新密碼、再輸入一次 → 儲存。只能改自己的密碼。
- 規則：至少 6 碼、兩次要一樣、不能跟舊密碼一樣（Supabase 擋）。
- 不要求舊密碼、不寄驗證信（能打開選單的人已登入）。
- 改完這台不用重新登入，**其他裝置一律強制登出**（下一次換頁／重新整理就回登入頁）；若這台裝置存了「記住帳號密碼」且是同一個 Email，一併更新成新密碼。

## 不做
- 忘記密碼（寄信重設）。
- 老師改完後通知家長；家長仍可用「重設密碼」覆蓋。

# 測試回饋：司機車程每 5 分一格、多站接送的預覽（Elsa 11/19）

狀態：已實作（2026-11-19）

## 問題
1. 單程車程選項只有 0／15／30／45／60／90，太少，希望以 5 分鐘為單位。
2. 一趟接送中途繞好幾站（家接豪哥、外傭 → 校車下車點等妹妹 → 便利商店 → C&C → 送外傭回家），寫在「給司機的備註」裡；表單下方灰字卻寫「去程 17:00 上車：家 → C&C」，跟備註對不上。
3. 一鍵切換成別人的權限來看，不用登出登入。

## 審視
- BA：1、2 是排司機時每次都會碰到的；3 只有測試時用得到（實際使用者每人一個身分）。
- PM：這次只做 1、2 的小改；3 先教用無痕視窗，Peggy 也需要再做。多個停靠點的結構化欄位不做。

## 做法
- 選項：0、5、10……90，再加 105、120。地圖估算本來就進位到 5 分，會落在選項上。
- 預覽：**有寫備註時**不猜起訖點，只寫「去程 17:00 出發」「回程 19:30 接，約 20:00 回到」「路線照上面的備註」，加上「含車程 … 都不算空檔」。沒寫備註時跟原本一樣。
- 只改表單預覽；司機頁、司機時間表照舊。

# 測試回饋第五輪（2026-11-11）

## 一、語音取消找不到行程（Peggy）
「今天早上7:30游泳取消」→ 找「游泳 小杜」0 筆。那天 07:30 的行程標題是「小杜」，關鍵字要「每個詞都對到」才算，又被 AI 多加了詞。
- AI 多回傳 `targetTime`（原本那筆幾點）；提示詞要求 query 只放使用者講的詞，不自己從習慣補人名。
- 找候選依序放寬：全部詞都對到 → 任一詞對到 → 有講日期就列那天的行程（有講時間只留同時間）。
- 放寬後找到的，畫面說明「找不到標題有「…」的行程，下面是同一時間（07:30）的行程」，仍要使用者點選確認才刪。

## 二、月曆格子看不到自己的主要行程（Peggy）
格子只放 3 筆、依時間排，小孩／豪哥早上的課排前面，自己 14:00 的美甲被擠進「+4 筆」。
- 超過 3 筆時，先留位置給本人（未指定主角或主角是本人）與重要行程，再依時間排。
- 「豪哥 空…」空檔線：是人物管理裡豪哥的「月曆空檔」設定（預設不顯示，有人改成顯示），改回「不顯示」即可，不改程式。

## 三、Peggy 打開的第一頁要是週行程表（Elsa）
- 登入後、打開 App（`/`）時：帳號本人在人物裡有勾「本人」（行事曆主人，如 Peggy）→ 週行程表；其他人（豪哥、家教）→ 月曆。
- App 圖示的開啟網址改成 `/`。iPhone／iPad 已加到主畫面的圖示可能還記著舊網址，要刪掉重加一次。
